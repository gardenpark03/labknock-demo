# LabKnock 웹 프로토타입

소프트웨어공학개론 팀 프로젝트 '랩노크(LabKnock)'의 요구사항 명세(SRS v1.3)를 브라우저 안에서 실제 서비스처럼 동작하게 만든 발표·시연용 웹 프로토타입입니다.

- 첫 화면은 홈입니다. 서비스 소개와 검색, 마감이 가까운 공고, 학생·연구실 관리자 이용 방법, 자주 묻는 질문이 있고, 로그인하면 계정별 바로 가기가 보입니다.
- 회원가입·로그인·학교 이메일 확인·프로필·연구실 소속 인증·운영 보조 검토와 탐색·지원·심사 흐름이 브라우저 안에서 동작합니다. 서버와 실제 메일 대신 브라우저 저장소와 '가상 메일함'을 씁니다.
- 인물·연구실·공고·첨부와 증빙 PDF는 모두 가상 예시 데이터이며, 실제 서비스가 아닙니다. 비밀번호 처리 등 보안은 시연 수준입니다.
- 로그인 화면의 '발표용 데모 계정'(학생·연구실 관리자·관리자 신청자·운영 보조)으로 바로 로그인할 수 있습니다. 비밀번호는 `labknock-demo-2026`입니다.
- 데이터는 이 브라우저에만 저장되고, 화면 아래 '데모 데이터 초기화'로 처음 상태로 돌아갑니다.
