# LabKnock 클릭 프로토타입

소프트웨어공학개론 팀 프로젝트 '랩노크(LabKnock)'의 요구사항 명세(SRS v1.3) 화면 흐름을 브라우저에서 눌러 볼 수 있게 만든 발표·시연용 프로토타입입니다.

- 서버·DB·실제 로그인·메일 발송 없이 브라우저 안에서 화면 상태만 재현합니다.
- 인물·연구실·공고·첨부 PDF는 모두 가상 예시 데이터이며, 실제 서비스가 아닙니다.
- 오른쪽 위 '데모 계정'에서 방문자·학생·연구실 관리자·관리자 신청자로 바꿔 볼 수 있습니다.
- 데이터는 같은 탭 안에서만 유지되고, 화면 아래 '데모 데이터 초기화'로 처음 상태로 돌아갑니다.
